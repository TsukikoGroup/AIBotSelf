## ✨ Возможности

- **До трёх команд в одном профиле** — включайте `/up`, `/bump` и `/like` независимо.
- **Собственный интервал для каждой команды** — от 1 до 168 часов.
- **Несколько серверов одновременно** — отдельный профиль для каждого аккаунта, сервера или канала.
- **Три режима работы**:
  - `Таймер` — команды выполняются по заданному интервалу;
  - `Упоминание` — запуск после упоминания выбранной роли;
  - `Совместный` — таймер и упоминания работают вместе.
- **Планировщик** — разовые задачи с датой, временем, секундами и повторами.
- **Telegram-уведомления** — подключения, ошибки и результаты планировщика.
- **HTTP/SOCKS5-прокси** для Telegram.
- **Системный трей** — приложение можно полностью скрыть и оставить работать в фоне.
- **Защита токенов через Windows DPAPI**.
- **Современный интерфейс** — темы, фон, затемнение, анимации, toast-уведомления и фильтруемый журнал.

## 🖼️ Интерфейс

## 🚀 Установка

### Готовая версия

1. Откройте раздел [Releases](../../releases/latest).
2. Скачайте `AI-BOT-BY-LISOVSKY-Setup-2.7.0.exe`.
3. Запустите установщик и следуйте инструкциям.
4. При желании включите ярлык на рабочем столе и автозапуск вместе с Windows.

Установка выполняется в профиль текущего пользователя и не требует прав администратора.

### Запуск из исходников

Понадобятся Windows 10/11, [Python](https://www.python.org/downloads/) и Git.

```powershell
# Откройте PowerShell в папке проекта
py -3.14 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

Если PowerShell блокирует активацию окружения:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

## ⚙️ Настройка

### 1. Создайте профиль

Откройте раздел **Аккаунты**, добавьте профиль и заполните:

- название профиля;
- Discord-токен;
- ID канала;
- ID приложений для нужных команд;
- ID роли, если используется режим по упоминанию.

### 2. Выберите команды

В одном профиле можно включить одну, две или сразу три команды:

```text
UP     каждые 4 ч.
BUMP   каждые 2 ч.
LIKE   каждые 6 ч.
```

Для каждой включённой команды требуется корректный ID соответствующего Discord-приложения.

### 3. Настройте несколько серверов

Создайте отдельный профиль для каждого сервера или канала. Профили работают независимо и могут использовать разные:

- токены;
- каналы;
- приложения;
- команды;
- интервалы.

### 4. Запустите помощника

Сохраните профили, вернитесь на главную страницу и нажмите **Запустить помощника**. Для изменения профилей сначала остановите активные подключения.

## 🔔 Telegram-уведомления

Telegram-интеграция может сообщать о:

- подключении Discord-профиля;
- ошибках выполнения;
- запуске и результате задач планировщика.

Поддерживаются прямое подключение, HTTP-прокси и SOCKS5-прокси.

> [!IMPORTANT]
> Telegram bot token также является секретом. Не публикуйте его в Issues, логах, скриншотах или файлах репозитория. Используйте только доверенные прокси-серверы.

## 🔐 Безопасность

- Discord- и Telegram-токены сохраняются в зашифрованном виде через **Windows DPAPI**.
- Зашифрованные данные привязаны к текущему пользователю Windows.
- Настройки записываются атомарно, а резервная копия используется при восстановлении.
- Токены маскируются в интерфейсе и диагностических сообщениях.
- Локальные настройки хранятся в `%APPDATA%\AIBot`.

DPAPI защищает данные на диске, но не делает публикацию файла настроек безопасной. Никогда не добавляйте `settings.json`, токены или приватные логи в Git.

## 🛠️ Сборка из исходников

Полная сборка EXE и установщика:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\build.ps1
```

Только standalone EXE:

```powershell
.\build.ps1 -SkipInstaller
```

Скрипт автоматически:

1. создаёт изолированное окружение `.build-venv`;
2. устанавливает зависимости и PyInstaller;
3. генерирует иконку приложения;
4. проверяет синтаксис `main.py`;
5. собирает standalone EXE;
6. создаёт установщик через Inno Setup 6.

Результаты:

```text
dist\AI BOT BY LISOVSKY.exe
installer\AI-BOT-BY-LISOVSKY-Setup-2.7.0.exe
```

Если Inno Setup отсутствует, скрипт попробует установить его через `winget`.

## ❓ Частые вопросы

<details>
<summary><b>Почему профиль не запускается?</b></summary>

Проверьте токен, ID канала и ID приложений для всех включённых команд. Все Discord ID должны состоять только из цифр.
</details>

<details>
<summary><b>Можно ли использовать один профиль на нескольких серверах?</b></summary>

Один профиль работает с одним настроенным каналом. Для нескольких серверов создайте несколько профилей — они будут запущены параллельно.
</details>

<details>
<summary><b>Почему нельзя изменить профиль во время работы?</b></summary>

Это защита от рассинхронизации активных таймеров и сохранённых настроек. Остановите помощника, внесите изменения и запустите его снова.
</details>

<details>
<summary><b>Можно ли перенести зашифрованные настройки на другой компьютер?</b></summary>

Нет. DPAPI привязывает секреты к текущему профилю Windows. На другом компьютере токены потребуется ввести заново.
</details>
